# 🎉 BIENVENUE DANS EDULINUX !

## 👋 Salut !

Félicitations ! Tu as maintenant accès à **EduLinux**, une plateforme complète pour apprendre Linux de manière ludique et interactive.

---

## ⚡ DÉMARRAGE IMMÉDIAT

### 🚀 Étape 1 : Ouvre ton navigateur

Clique sur ce lien ou copie-le dans ton navigateur :

```
http://localhost:3000
```

### 🎮 Étape 2 : Clique sur "Commencer l'Aventure"

Tu verras la page d'accueil avec :
- Présentation d'EduLinux
- Les 30 niveaux disponibles
- Un gros bouton bleu "🚀 Commencer l'Aventure"

**Clique dessus !**

### 🏁 Étape 3 : Lance le Niveau 1

Sur la page des niveaux :
1. Tu verras une grille de 30 niveaux
2. Seul le **Niveau 1** est débloqué (les autres ont un 🔒)
3. Clique sur **Niveau 1 - Découvrir le terminal**

### 💻 Étape 4 : Tape ta première commande

Tu arrives sur une page avec :
- **Gauche** : Informations sur le niveau
- **Droite** : Un terminal noir (comme un vrai terminal Linux)

Dans le terminal, tape :
```bash
echo Hello World
```

Appuie sur **Entrée** ✨

### 🎉 Étape 5 : Célèbre ton succès !

Tu verras :
- ✅ Message de validation
- 🎉 Modal de célébration
- ⭐ +100 XP
- 🔓 Niveau 2 débloqué

**Bravo ! Tu viens de compléter ton premier niveau !** 🏆

## 💡 Conseils Rapides

### Dans le Terminal
- **Entrée** : Exécuter la commande
- **↑** : Commande précédente
- **↓** : Commande suivante

### Besoin d'Aide ?
1. Lis l'**objectif** (panneau gauche)
2. Consulte les **indices** (en bas du terminal)
3. Vérifie la **description** (panneau gauche)
4. Regarde [COMMANDS.md](./COMMANDS.md) pour la référence complète

### Bloqué ?
- Ne pas paniquer ! 😊
- Chaque niveau a plusieurs indices
- La documentation est complète
- Les commandes sont documentées
